## 4. 지켜야 할 결정 (바꾸려면 기획 계정에 먼저 묻기)
- AI는 **영양 숫자를 내지 않음** (구조 · 짝짓기 · 모르는 것 목록만). 숫자는 식품표 · 내 식품에서 앱 코드가 계산
- API 키는 앱 코드에 넣지 않음. 몸 정보는 AI에 보내지 않음
- 몸 정보 · 체중 기록은 **본인만** 읽고 씀 (`private/{uid}`). 식단 · 목표 숫자 · 레시피·식품은 둘이 공유
- 탄단지 목표는 2025 한국인 영양소 섭취기준 범위 안 (단백질 20% 상한)
- 안내 문구("참고용 추천 · 의학적 진단·처방이 아니어서 효력 없음 · 전문가와 상의")는 문구 그대로
- 빨강은 경고 전용 · 색은 테마 토큰만 · 탄단지는 사람 색 진하기 · 수면 기록 없음
- 이름: 화면 제목 **짝꿍 식탁**
