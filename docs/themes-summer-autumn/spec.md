## 3. 장식 (`pixel-skin-summer-autumn.css`)
- 머리 장식: 24×14칸 SVG를 3배(72×42) 가로 반복, 밤 판은 24×20칸(72×60) → 밤 판은 머리말을 56px 내림(봄소풍 밤과 같음)
- 바탕: 28×28칸 SVG 3배(84px) + 24px 옅은 체크. 밤 체크는 흰색 2.5%
- 밤 판 고른 탭 테두리 = `--btn-lo` (봄소풍 밤과 같음)
- SVG는 판마다 파일이 따로라 색이 파일 안에 고정 — 색 하드코딩 검사에서 그림 · 장식 파일은 예외(겨울 때 정한 것)
