## 2. 질문 (id 는 저장된 답의 열쇠 — 바꾸지 말 것, `{next}` = 다음 해)
**올해 우리의 취향** t1 올해 우리 플레이리스트 1번 곡 · t2 짝꿍이랑 또 가고 싶은 곳(힌트: 별점 1위 곳) · t3 짝꿍이랑 먹을 때 질리지 않았던 최애 메뉴 · t4 짝꿍 덕분에 잘 쓴 물건 세 가지 · t5 짝꿍이랑 다시 보고 싶은 영화나 책
**올해의 발견** f1 짝꿍이랑 처음 가 본 곳 중 가장 좋았던 곳(힌트: 새로 칠한 곳) · f2 처음 도전해 본 것 · f3 의외로 우리 둘이 잘 맞았던 것 · f4 짝꿍에게서 새로 배운 것 · f5 짝꿍 옆에서 내가 쉬는 방법 · f6 새로 알게 된 짝꿍의 습관
**올해의 변화** c1 1년 전과 달라진 짝꿍의 모습 · c2 1년 전보다 우리가 능숙해진 것(힌트: 루틴) · c3 우리의 가장 큰 지출(힌트: 영수증) · c4 짝꿍 때문에 새로 생긴 관심사 · c5 우리가 더는 하지 않게 된 것 · c6 짝꿍을 가장 칭찬해 주고 싶은 점
**올해의 우리** u1 짝꿍에게 들어서 가장 기뻤던 말 · u2 짝꿍에게 고맙다고 꼭 전하고 싶은 순간 · u3 짝꿍 덕분에 새로 알게 된 사람 · u4 우리의 가장 기억에 남는 날(힌트: 둘 다 해낸 날 최다 달) · u5 가장 자주 본 짝꿍의 표정 · u6 내가 짝꿍에게 가장 자주 한 말
**{next} 우리** n1 {next}년 우리의 추구미 · n2 내년에도 계속하고 싶은 것(힌트: 루틴) · n3 내년에 꼭 가 보고 싶은 곳 · n4 같이 새로 배워 보고 싶은 것 · **n5 내년의 짝꿍에게 한 줄(타임캡슐)** · **n6 {next}년 첫 장에 쓸 우리의 한 마디(마지막 장)**

  - 연말결산 문서가 없는 해(서버가 못 만듦)도 「펼쳐 보기」를 누르면 문답 카드만으로 덱이 열림

## 4. 데이터 · 규칙
```
yearqa/{YYYY}            { sealed: { uid: serverTimestamp } }      ← 봉투 붙인 표시 (둘 다 읽음)
yearqa/{YYYY}/a/{uid}    { answers: { t1: '…', … }, sealed: bool, updatedAt, sealedAt? }
```
- 봉투 붙이기 = 한 batch: `a/{나}`(sealed true) + `yearqa/{YYYY}.sealed.{나}` (set merge). 규칙이 `getAfter` 로 같이 오는지 확인
- `a/{uid}` get: 본인 · 또는 (그 문서 sealed && 내 문서 sealed && `request.time ≥ 다음 해 1월 1일 0시 서울`). list 막음. 만들기 · 고치기는 본인만, 정해진 칸, 답 40개까지, 붙인 봉투는 못 뗌(sealed true → false 거부). 지우기 없음
- 표시 문서: 만들기 · 고치기는 내 칸 하나만 · 서버 시각 · 내 답이 sealed 일 때만. 지우기 없음
- 답 한 개 300자 · 줄바꿈 정리는 앱(`clean`)에서. 규칙은 칸 · 개수만 (지도 안 값의 길이는 규칙으로 못 셈)
- 짝꿍 답은 펼쳐지기 전엔 **구독도 하지 않음** (`js/app-yearqa.js` `syncPartner`) — 규칙이 막기 전에 앱이 먼저 지킴
