## 2. 색 토큰 — `tokens-spring.css`
- 두 판 모두 겨울 판과 같은 토큰 이름. `tokens-draft.css`에 있는데 여기 없는 토큰(예: `--toast-*` 외 것, `--tomato-*`)은 **같은 이름의 겨울 판 값을 이 계열로 옮겨 채우고** `## 바뀐 것`에 적어 주세요
- 글자 대비: **21쌍 × 2판 모두 4.5:1 이상** (`contrast.md`, `tokens.py`로 다시 계산 가능)

## 3. 장식 (그림 파일 예외 — 색이 SVG 안에 고정)
| 파일 | 칸 | 보이는 크기 | 어디 |
|---|---|---|---|
| `head.svg` | 24×14 | 72×42 (3배), 가로로 반복 | 낮 머리 장식: 깃발 줄(분홍 · 노랑 · 초록) + 꽃잎 |
| `head-night.svg` | 24×20 | 72×60 (3배) | 밤: 깃발 줄 + 아래 종이 등 줄(노랑 · 분홍). 밤 판은 머리말 위 여백 56px(겨울 밤과 같음) |
| `bg.svg` | 28×28 | 84px 반복 | 낮 바탕: 꽃잎 + 흰 점, 아래에 24px 옅은 체크(`rgba(224,122,152,.08)`) |
| `bg-night.svg` | 28×28 | 84px 반복 | 밤 바탕: 옅은 꽃잎 + 별 점, 체크 `rgba(255,255,255,.025)` |
- CSS: `pixel-skin-spring.css` 맨 아래 묶음(봄소풍 선택자만). 다른 테마 화면은 바뀌지 않아야 해요
- 밤 판 점선 구분선 색 `#4B4166`

## 4. 그림 S1~S4
| 자리 | 그림 | 지금 파일(임시) | 배율 | 보이는 크기 |
|---|---|---|---|---|
| S1 머리말 오른쪽 | 피크닉 바구니 | `s1.png` 18×16 | 4배 | 72×64 |
| S2 짝꿍 식탁 카드 | 딸기 샌드위치 둘 | `s2.png` 20×10 | 4배 | 80×40 |

- **지금 PNG는 기획 계정이 직접 찍은 임시 그림**이에요(크림 1칸 테두리 포함, 4장 합계 1.2KB). 테마 동작 · 크기 · 배율 확인용으로 그대로 넣어도 되고, Gemini 그림을 받으면 같은 이름으로 바꿔요(`prompts.md`)
- 받은 그림의 칸 크기가 달라지면 배율은 **정수만**, 보이는 크기가 위 표 ±16px 안에 들게 골라 `## 바뀐 것`에 적기
- 낮 · 밤 같은 그림(크림 테두리 덕에 밤에도 또렷함)

## 5. 바뀌는 것 / 안 바뀌는 것
- 바뀜: `themes.js`에 테마 하나(판 두 개) · `tokens.css`에 두 판 · 스킨 CSS 묶음 · `assets/themes/spring-picnic/` 8개 파일 · 설정 화면 테마 카드 미리보기(CSS만, 목업 T1)
- 안 바뀜: 다른 테마 · 도트 부품 · 글꼴 표(W2에서 정한 갈무리 크기) · 낮밤 규칙

## 6. 용량
