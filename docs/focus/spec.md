## 1. 정한 것

### 사용자 결정 (11-25, 바꾸지 않음)
1. 아래 탭 5개 유지 · 순서 **루틴 · 시간표 · 집중 · 할 일 · 전체**
2. 돌아보기 탭 → 전체 탭 「우리 둘」 바로 아래 카드. 단짝 기능 2×2 큰 카드는 그대로, 길어지면 스크롤
3. 탭 이름 「집중」 · 앱을 열면 여전히 루틴 탭
4. 엄격 모드는 사람마다 고름(느슨이 기본). 엄격 = 앱을 나가고 5초 뒤 「자리 비움」, 돌아와 「다시 시작」
5. 하루 기준 새벽 5시
6. 알림: 짝꿍이 집중을 시작할 때마다 + 「같이 하자」 버튼
7. 과목 = 시간표 카테고리 그대로(둘이 같은 목록, 16개까지) + 짧은 이름(8자) 선택
8. 둘 사이 순위 · 뽀모도로는 F1에 없음

### 기획 계정이 물어서 정한 것 (11-25 사용자)
| 물음 | 답 |
|---|---|
| 집중 화면 새 그림 자리(S5)를 만들지 | **새 그림 없음. 테마의 S3 그림(할 일 다 끝냄)을 집중 화면에 적극적으로 씀** — 「할 일을 다 끝낸 적이 거의 없어서 S3를 본 적이 없다」(사용자). S3는 할 일 탭 자리에도 그대로 남음 |
| 집중 탭 맨 위에 무엇을 크게 | **내 오늘 합계 크게 + 「🔥 함께」 · 「● 다진」 칩** (시안 A-1 그대로) |
| 엄격 모드 「자리 비움」을 짝꿍에게 얼마나 | **상태만**: 짝꿍 카드에 「잠깐 자리 비움」. 횟수 · 시간 · 알림 없음, 다른 탭 띠에도 안 나옴 |

### 기획 계정이 정한 것 (목업을 만들며 — 다르게 하고 싶으면 「바뀐 것」에)
- **진행 링 색 = 테마의 `--strong`** (시안 A-2의 연보라 = `--me`에서 바꿈). 낮 테마의 사람 색은 옅어서 링과 링 바탕이 1.2~1.5:1로 거의 안 보였음 → `--strong`은 58판 모두 3:1 이상(Cosmic Dream만 `--accent`). 내 색은 링 끝 동그라미로 남김 → `tokens-focus.css`
- **링 한 바퀴 = 1시간.** 1시간이 넘으면 처음부터 다시 채움(숫자가 정확한 시간을 보여 줌)
- **「같이 하자」와 「같이 하기」를 나눔**: 짝꿍이 쉬는 중 → 「같이 하자」(알림 보내기) / 짝꿍이 집중 중 → 「같이 하기」(나도 바로 시작)
- **어제와 비교는 늘었을 때만** 「어제보다 +40분」, 줄었으면 「어제 4:00」처럼 숫자만(꾸짖지 않기)
- 과목 목록은 최근 쓴 순으로 3개 + 「과목 더 보기 · N개」
- 집중 탭 머리말에서는 **도트 테마 S1 그림을 그리지 않음**(오른쪽 ⚙ 버튼 자리). 머리 장식(`head.svg`)은 그대로
- 끝냄 요약에 S3를 한 번 더 크게. 도트가 아닌 테마는 ✓ 동그라미

### 3-3. S3 그림 (사용자 결정 — 새 그림 없이 S3를 적극적으로)
- 도트 테마 22개만. 그림 파일 = 지금의 `s3.png` 그대로(할 일 탭과 같은 파일)
- 자리: 안내 한 줄 아래, 높이 140px 칸의 가운데 아래쪽에 맞춤
- 크기: **할 일 탭과 같은 정수 배율**. 그 배율로 높이가 140px을 넘으면 한 단계 낮은 정수 배율(×4 → ×3)
- 움직임: 집중 중에만 2px 위아래로 1초마다 한 칸씩(`steps(1)`, 숨 쉬듯). 쉬는 중 · 자리 비움은 멈춤 + 55% 투명. `prefers-reduced-motion: reduce`면 움직이지 않음
- 숨김: 화면 높이 700px 미만(320×568 등)이면 그리지 않음. 도트가 아닌 테마는 그 자리가 없고 링이 커짐(288px)
- 할 일 탭 S3 자리는 그대로 둠

### 3-4. 끝냄 요약 (`sp-14` · `ci-14` · `ws-14`)
- 끝내기를 누르면 집중 화면이 이 화면으로 바뀜
- 맨 위: 도트 테마 = **S3를 할 일 탭 배율 그대로**(높이 제한 없음) / 다른 테마 = 96px `--tint` 동그라미 안 ✓
- 큰 글 「오늘 3:20 집중했어요」(오늘 합계 H:MM) · 작은 글 「이번에는 공부 · 해부학 1:12」
- 두 칸: 「🔥 다진 님과 함께 1:05」(오늘 함께, 0이면 칸 대신 「이번 주 다진 6:40」) · 「이번 주 나 7:55」
- 아래: [시간 고치기](글자 버튼 → 4-5 시트, 방금 기록) · [확인] → 집중 탭
- 1분 안에 끝낸 기록은 저장하지 않고 토스트 「1분이 안 돼서 기록하지 않았어요」 — *기획 계정 가정*

## 4. 시트

모두 기존 `.sheet`(위 모서리 24px, 손잡이) 그대로. 도트 테마는 위 외곽선 3px.

### 4-1. 과목 고르기 / 짧은 이름 (`sp-20`)
- 제목 「무엇을 집중할까요?」 · 설명 「시간표 카테고리와 같은 목록이에요.」
- 카테고리 3열 버튼(이모지 + 이름, 최근 쓴 순 6개) + 「카테고리 10개 더 ›」(펼치면 16개까지 모두)
- 「짧은 이름 (고르지 않아도 돼요)」 입력(8자, 「3/8」) + 최근 쓴 짧은 이름 칩(이 카테고리에서 쓴 것, 5개까지)
- 버튼 「공부 · 해부학 시작」(짧은 이름 없으면 「공부 시작」)
- 「같이 하기」로 열면 내 마지막 과목이 골라진 채. 짝꿍 과목을 따라가지 않음

### 4-2. 집중 설정 (`sp-21`)
- 제목 「집중 설정」 · 「나에게만 적용돼요. 다진 님은 따로 골라요.」
- 두 칸 고르기 [느슨] [🔒 엄격] + 고른 쪽 설명 상자 `--tint`
  - **느슨 (기본)**: 「다른 앱을 써도 시간이 계속 흘러요. 직접 끝낼 때까지 집중 중이에요.」
  - **🔒 엄격**: 「앱을 나가고 5초가 지나면 「자리 비움」이 돼요. 돌아와서 「다시 시작」을 누르면 이어져요. 나가 있던 시간은 빼요.」
- 아래 작은 글 「다진 님에게는 「잠깐 자리 비움」만 보여요. 몇 번 비웠는지는 보이지 않아요.」 · 「집중 중에는 바꿀 수 없어요. 다음 집중부터 적용돼요.」(집중 중에 열었을 때만)
- 알림 스위치는 여기 말고 전체 탭 › 알림 시트에 「집중」 묶음으로(8-4)

### 4-3. 「아직 하고 있어요?」 (`sp-22`)
- 집중 3시간이 되면(앱이 열려 있으면 바로, 아니면 다음에 열 때) 집중 화면 위에
- 「아직 하고 있어요?」 · 「23:10에 시작해서 3시간째 집중 중이에요. 6시간이 지나면 자동으로 멈춰요.」
- [네, 계속할게요] → 닫고 다음은 묻지 않음(6시간에 서버가 닫음) · [여기서 끝내기] → 끝냄 요약
- 바깥을 눌러 닫으면 「네」와 같음

### 4-4. 「언제 끝났어요?」 (`sp-23`)
- 서버가 6시간에 닫은 기록이 있을 때, 다음에 앱을 열면 집중 탭 위에 한 번
- 「23:10에 시작한 집중, 언제 끝났어요?」 · 「6시간이 지나 자동으로 멈춰 두었어요. 끝난 시각을 고르면 그만큼만 기록해요.」
- 칩: 「마지막으로 앱을 본 01:42」(있으면, 기본 선택) · 시작 + 정시들(「02:00」 「03:00」…, 6시간 안) · 「직접 고르기」 시각 입력(시작 ~ 시작+6시간, 날짜 작게)
- 버튼 「2:32 기록하기」(고른 만큼) · 글자 버튼 「기록하지 않을래요」(기록 지움)
- 함께 시간은 고른 끝 시각까지로 다시 계산

### 4-5. 기록 고치기 (`sp-24`)
- 여는 곳: 끝냄 요약 「시간 고치기」 · 오늘 카드를 누르면 나오는 「오늘 기록」 목록(시작 – 끝 · 과목 · 시간, 줄을 누르면 이 시트)
- 「기록 고치기」 · 「오늘 · 공부 · 해부학」 · 시작 / 끝 시각 · 과목(누르면 4-1 시트, 시작 버튼 대신 「바꾸기」) · 「고치면 함께 시간도 다시 계산해요. 지금보다 늦은 시각은 고를 수 없어요.」 · [1:12 저장] · 「이 기록 지우기」(`--warn` 글자 — 지우기는 경고 색 써도 되는 유일한 자리)
- 지우기 확인: 「이 기록을 지울까요? 1:12가 오늘 합계에서 빠져요.」 [지우기] [그대로 두기]
- 다른 기록과 겹치게 고치면 저장 버튼 대신 「19:50 ~ 20:10 기록과 겹쳐요」(`--warn`이 아니라 `--tint-text`)
- 짝꿍 기록은 볼 수만 있고 고칠 수 없음

## 5. 이번 주 그래프 (`sp-02` 아래)

- 카드 제목 「이번 주」 + 범례 `■나 ■다진 ■함께`(10px 네모, 둥근 3px)
- 월 ~ 일 7칸, 하루에 막대 둘(나 `--me` · 다진 `--her`, 폭 9px, 사이 3px). 막대 높이 = 그날 시간 / 이번 주 가장 긴 날
- **함께 시간은 두 막대의 아래쪽 조각**(`--both`), 사람 색 조각과 2px 틈(`--surface`)으로 나눔 — Soft Pastel에서 `--both`(#D98E94)와 `--her`(#D78EAD)가 거의 같은 색이라 틈으로 구분
- 0인 날 = 3px `--empty` 바닥 줄
- 요일 글자 12px `--sub`. **오늘** = `--today` 굵게 + 밑줄 2px. 오지 않은 날 = `--faint`(글자 아닌 자리 표시라 대비 예외 — 기존 달력과 같은 규칙)
- 그래프 아래 한 줄: 「오늘 · 나 **3:20** · 다진 **2:58** · 함께 **1:05**」. 막대를 누르면 그날로 바뀜(「화 · 나 1:35 · …」)
- 주 시작 = 월요일 새벽 5시
- 화면 읽기: 그래프 전체 `aria-label` = 「이번 주. 월 나 2시간 20분 다진 2시간 …」

## 6. 띠 · 탭 아이콘 점

### 6-1. 다른 탭의 띠 (`sp-32` ~ `sp-34`, `cin-32`)
- 자리: 루틴 · 시간표 · 할 일 · 전체 탭의 **머리말 바로 아래**, 첫 카드 위. 위 간격 12px
- 모양: 높이 48px, 모서리 14px, `--surface` 바탕, 1.5px 테두리(짝꿍 띠 `--her` · 내 띠 `--me` · 함께 `--both`). 도트 테마는 3px `--ol` 외곽선 + 왼쪽 안쪽 6px 사람 색 막대
- 띠 전체가 한 버튼(눌러도 같은 곳). 오른쪽 글자 버튼은 `--tint-text` 굵게

| 경우 | 왼쪽 | 오른쪽 | 누르면 |
|---|---|---|---|
| 짝꿍만 집중 | 「● 다진 · 공부 중 0:48」(점 = 짝꿍 색, 시간 = 짝꿍 이번 시간) | 「같이 하기 ›」 | 과목 시트(4-1) → 시작하면 집중 화면 |
| 나만 집중 | 「● 나 · 공부 · 해부학 1:12」 | 「보기 ›」 | 집중 화면 |
| 둘 다 | 「🔥 함께 집중 중 32분」 | 「보기 ›」 | 집중 화면 |
| 나 잠깐 쉬는 중 | 「⏸ 나 · 잠깐 쉬는 중 3분」 | 「보기 ›」 | 집중 화면 |
| 짝꿍 쉬는 중 · 자리 비움 · 아무도 안 함 | 띠 없음 | | |

- 시간은 1분마다 바뀜(초 없음). 줄이 넘치면 왼쪽 글이 「…」으로 줄어듦, 오른쪽은 줄지 않음
- 띠가 생기고 사라질 때 아래 내용이 밀리지 않게 200ms 높이 전환(줄인 움직임 설정이면 바로)
- 결산 보기 화면 · 시트 위에는 띠 없음

### 6-2. 탭 아이콘 (`sp-35`)
- 집중 = **스톱워치 선 아이콘** 24px(원 r7 + 꼭지 + 바늘 + 오른쪽 위 짧은 선). 다른 4개와 **같은 선 굵기 값**(저장소 아이콘의 stroke-width 그대로), 끝 모양도 같게. 도트 테마는 기존처럼 각진 끝
- 목업 SVG: `<circle cx="12" cy="13.5" r="7"/><path d="M12 13.5V9.5M10 3.5h4M18.2 7.3l1.3-1.3"/>`

### 6-3. 점
- 아이콘 오른쪽 위(가운데 + 6px, 위 4px)에 **9px 점**, 탭 바탕색 2px 테두리
- 짝꿍만 → 짝꿍 색 · 나만 → 내 색 · 둘 다 → 두 점 3px 겹침(내 색 아래, 짝꿍 색 위)
- **집중 탭에 있을 때는 점 없음**(화면에 다 보임)
- 자리 비움 · 쉬는 중 → 점 없음
- 탭 aria-label: 「집중 · 다진 님 집중 중」 / 「집중 · 함께 집중 중」

## 7. 숫자 · 시간

### 7-1. 표시 꼴
| 자리 | 꼴 | 예 |
|---|---|---|
| 오늘 카드 큰 숫자 · 집중 화면 가운데 | H:MM:SS (1초마다) | 3:20:15 · 0:04:09 |
| 칩 · 과목 줄 · 그래프 줄 · 끝냄 요약 | H:MM | 1:05 · 0:40 |
| 짝꿍 상태 · 띠의 분 | 60분 미만 「48분」, 넘으면 H:MM | 48분 · 1:12 |
| 집중 화면 짝꿍 시간 | H:MM | 0:48 |
- 숫자는 모두 `font-variant-numeric: tabular-nums`(도트 테마는 7-3)
- 시간 계산은 시작 시각 기준(5절 구현 뼈대) — 화면은 1초 타이머로 다시 그림, 백그라운드에서 돌아오면 바로 다시 계산

### 7-2. 하루 · 주
- 오늘 = 새벽 5시 ~ 다음 날 새벽 5시. 5시를 넘어 이어진 집중은 **5시에서 나눠** 앞은 어제, 뒤는 오늘로 셈(집중 화면 숫자는 이어서 보이고, 「오늘 합계」만 5시에 다시 셈)
- 주 = 월요일 새벽 5시부터

### 7-3. 도트 테마 숫자
- 큰 숫자는 **Galmuri 계열 고정폭 숫자**(예: GalmuriMono11 — 숫자 · 콜론만 subset, 몇 KB)로 48px(12px 격자 4배). 고정폭이 아니면 1초마다 숫자 폭이 흔들림
- 그 밖의 글씨는 지금 도트 글씨 크기 표(12 · 15 · 24 · 36) 그대로
- 「글씨체: 기본」(v61)을 고른 사람은 Pretendard tabular

### 7-4. 어제와 비교 (오늘 카드 오른쪽 위)
- 같은 시각까지가 아니라 **어제 하루 전체**와 비교
- 오늘이 더 많으면 「어제보다 +40분」 / 같거나 적으면 「어제 4:00」 / 어제 0이면 비움

## 8. 문구

말투: 「~해요」, 짧게, 꾸짖지 않기. 짝꿍 이름 뒤 「님」은 알림 · 안내 문장에만, 카드 · 칩 · 띠에서는 이름만.

| 머리말 설정 | ⚙ 느슨 · 🔒 엄격 |
| 짝꿍 카드 | 같이 하자 · 같이 하기 · 보냈어요 |
| 과목 | 과목 · ▶ 한 번이면 시작 · 과목 더 보기 · ＋ 짧은 이름 붙여 시작 |
| 나 집중 중 | 집중 화면 열기 · 끝내기 |

| 처음 안내 | **과목 옆 ▶를 누르면 바로 시작해요.** 다진 님과 같은 시간에 집중하면 🔥 함께 시간이 쌓여요. |
| 짝꿍 상태 | 오늘 2:58 · 쉬는 중 · 오늘은 아직 쉬는 중이에요 · 집중 중 48분 · 잠깐 쉬는 중 · 잠깐 자리 비움 · 함께 32분째 |
| 집중 화면 | 집중하는 동안 화면이 꺼지지 않아요 · 이 기기에서는 화면이 꺼질 수 있어요 · 쉬는 시간은 집중 시간에 넣지 않아요 · 🔥 함께 집중 중 · 32분 · ⏸ 잠깐 쉬는 중 · 3분 |

| 끝냄 요약 | 오늘 3:20 집중했어요 · 이번에는 공부 · 해부학 1:12 · 🔥 다진 님과 함께 · 이번 주 나 |
| 그래프 | 이번 주 · 나 · 다진 · 함께 · 집중한 시간이 여기에 날마다 쌓여요. |

### 8-3. 토스트
- 「공부 · 해부학 시작했어요」(▶로 시작할 때만, 집중 화면이 열리면 없음)
- 「영어로 바꿨어요」 · 「1:12 집중했어요」(집중 탭에서 ■로 끝낼 때)
- 「다진 님에게 같이 하자고 보냈어요」 · 「30분 뒤에 다시 보낼 수 있어요」
- 「기록을 고쳤어요」 · 「기록을 지웠어요」 · 「1분이 안 돼서 기록하지 않았어요」
- 「쉬는 시간이 길어서 23:40에 끝냈어요」
- 연결 끊김: 「연결이 끊겨도 시간은 이 기기에서 계속 재요」

### 8-4. 알림 (F2에서 서버가 보냄 — 문구만 지금 정함)
| 언제 | 제목 | 본문 | 누르면 |
|---|---|---|---|
| 짝꿍이 집중 시작(내가 쉬는 중) | 📚 다진 님이 공부를 시작했어요 | 해부학 · 지금 같이 할까요? | `?tab=focus` |
| 짝꿍이 시작(내가 집중 중) | 🔥 다진 님도 시작했어요 | 지금부터 함께 집중 중이에요 | 집중 화면 |
| 같이 하자 | 💌 다진 님이 같이 집중하재요 | 지금 시작하면 함께 시간이 쌓여요 | `?tab=focus` |
| 3시간 | ⏱ 3시간째 집중 중이에요 | 아직 하고 있어요? 눌러서 알려 주세요 | 집중 화면 + 4-3 |
| 6시간 닫음 | 집중을 잠시 멈춰 두었어요 | 언제 끝났는지 알려 주면 시간을 맞춰 둘게요 | 집중 탭 + 4-4 |
- 제목 맨 앞 이모지 = 카테고리 이모지(없으면 ⏱). 짧은 이름이 없으면 본문 「지금 같이 할까요?」만
- 알림 시트(전체 › 알림)에 묶음 「집중」: 「짝꿍이 집중을 시작하면」(기본 켬) · 「같이 하자 받기」(기본 켬). 「짝꿍 알림」을 끄면 둘 다 안 감(지도 알림과 같은 규칙)
- 알림 거르기(구현 뼈대): 쉬다가 새로 시작할 때만 · 30분 안에 다시 시작하면 안 보냄 · 같이 하자 30분에 한 번

## 9. 접근성 · 화면 크기

- 누르는 자리 모두 44px 이상(▶ · ∨ · 띠 · 설정 알약 · 칩 아님)
- **320px** (`sp-40` · `sp-41` · `ci-41`): 좌우 여백 14px, 큰 숫자 38px, 링 208px, S3 숨김, 짝꿍 상태 줄 두 줄 허용, 탭 줄 좌우 4px
- **큰 글씨** (`sp-42` · `sp-43`, 기기 글자 130%): 과목 줄이 두 줄로(이름 위 · 시간과 ▶ 아래), 큰 숫자는 한 줄 유지(`white-space: nowrap` + `font-size: min(…, 13vw)`)
- 화면 읽기: 큰 숫자 = 「오늘 3시간 20분 15초」(1초마다 읽지 않게 `aria-live` 없음, 1분마다 바뀌는 숨은 글에만 `polite`) · 링은 `aria-hidden` · ▶ 버튼 「공부 시작」 · ■ 「공부 끝내기」
- 움직임 줄이기: S3 움직임 · 띠 전환 · 링 이어 그리기 없음
- 어두운 테마: 토큰만 쓰므로 따로 없음(`cd-*` · `wsn-*` · `cin-*`)
