# 탭 정리 (FT1) — 돌아보기 → 전체 탭

> 목업: `sp-30-all-tab` · `sp-31-review-from-all` · `sp-35-tabbar`, 테마별 `*-30-all-tab`
> FT1은 집중 화면 없이 먼저 만들 수 있게 나눴어요. 이때 집중 탭 자리는 집중 탭의 빈 껍데기(머리말 + 「준비 중」)로 두고, FC1에서 채워요. **출시는 FC1 · FT2와 한 번에.**

## 1. 아래 탭
| 지금 (v84) | 바뀐 뒤 |
|---|---|
| 루틴 · 시간표 · 할 일 · 돌아보기 · 전체 | **루틴 · 시간표 · 집중 · 할 일 · 전체** |
- `TABS`: `{ id: 'focus', label: '집중' }`을 시간표 뒤에 넣고 `look`(돌아보기)를 뺌. 다른 탭 id는 그대로
- 아이콘: 스톱워치 선 아이콘(`spec.md` 6-2). 크기 · 굵기 · 글자 12px · 탭 줄 높이(약 68px)는 그대로
- 앱을 열면 **루틴 탭**(그대로)
- 320px에서 다섯 글자 「루틴 · 시간표 · 집중 · 할 일 · 전체」 모두 한 줄(지금과 글자 수가 같음 — 「돌아보기」 4자 → 「집중」 2자라 오히려 여유)
- 저장된 마지막 탭이 `look`이면(기기에 남아 있을 수 있음) → `all`로 바꿔 열고 돌아보기 화면을 띄우지는 않음

## 2. 전체 탭 새 배치 (`sp-30`)
위에서부터, 섹션 사이 간격은 지금 `.sec`(위 20px · 아래 8px) 그대로:

| # | 블록 | 바뀜 |
|---|---|---|
| 1 | 머리말 「전체」 | 그대로 |
| 2 | 「우리 둘」 박스 | 그대로 |
| 3 | **소제목 「돌아보기」 + 돌아보기 카드** | 새로 |
| 4 | 소제목 「단짝 기능」 + 2×2 큰 카드 | 그대로(크기 · 순서 · 간격 10px) |
| 5 | 소제목 「설정」 + 목록 | 그대로 |

### 돌아보기 카드
- `.card` 한 장, 위 간격 = 「우리 둘」과 같은 섹션 간격
- 첫 줄: 「이번 주 우리」(15px 굵게) · 오른쪽 「모두 해낸 날 2일」(13px `--sub`)
- **이번 주 5단계 띠**: 월~일 7칸, 높이 26px, 칸 사이 6px, 모서리 7px. 색은 돌아보기 「주」와 같은 5단계 규칙(`--lv-full` · `--lv-half` · `--empty` · 루틴 없음 빗금 · 오지 않은 날 `--line` 1px 테두리), 오늘 = `--today` 2px 안쪽 테두리. 아래 요일 11px `--sub`
- 버튼 셋 [주] [달] [결산] — 높이 44px, 3열, 모서리 12px, `--line` 테두리. 누르면 돌아보기 화면을 그 칸으로 열기(3절)
  - 1~7일에 지난달 결산이 있으면 [결산] 오른쪽 위에 작은 「새로」 꼬리표(`--primary` / `--on-primary`) — 지금 돌아보기 위 칸의 「새로 나왔어요」와 같은 조건
- 아래 한 줄(12px `--sub`, 날짜에 따라):
  | 언제 | 문구 |
  |---|---|
  | 평소 | 12월 1일 아침에 11월 결산이 나와요 · 연말 문답도 여기서 열려요 (11월 중) / 「다음 달 1일 아침에 이번 달 결산이 나와요」 |
  | 1~7일, 결산 있음 | 11월 결산이 나왔어요 › (누르면 결산 보기 바로) |
  | 12월 1일 ~ 1월 31일 | 위 줄 + 한 줄 더 「💌 짝꿍과의 연말 문답 ›」(지금 돌아보기의 연말 문답 입구 카드를 이 한 줄로. 누르면 연말 문답) |
- 카드 전체를 눌러도 돌아보기 「주」로

### 스크롤 길이
- 390×844에서 전체 탭은 한 화면 반쯤(설정 목록이 첫 화면 아래로 내려감). 단짝 기능 2×2 첫 줄은 첫 화면 안에 보임(목업 기준 위에서 약 500px)
- 탭 줄 높이만큼 아래 여백, 마지막 「계정」 줄 아래 24px

## 3. 돌아보기 화면 (전체 탭에서 열림, `sp-31`)
- 지금 돌아보기 탭 화면을 **그대로 화면 하나로 띄움**(전체 탭 위에 쌓이는 화면). 아래 탭 줄은 보이고 「전체」가 켜진 채
- 머리말: 왼쪽 **‹ 뒤로**(44px, aria 「전체로 돌아가기」) + 제목 「돌아보기」(20px 굵게). 날짜 캡션 · 디데이 칩 없음
- 그 아래 지금의 「주 · 달 · 결산」 고르기부터 끝까지 그대로
- **뒤로 가기**: ‹ · 기기 뒤로 가기 · Esc → 전체 탭(스크롤 위치 그대로). `history.pushState`로 한 칸 쌓음
- 아래 탭 「전체」를 다시 누르면 → 전체 탭 맨 위로(돌아보기 닫힘). 다른 탭을 누르면 돌아보기는 닫힘
- 결산 보기(S4 표지 · 카드 넘기기)는 지금처럼 전체 화면으로 그 위에 열림. **S4는 그대로 둬도 됨** — 열리는 곳만 바뀌고 표지 화면 자체는 같음
- 다른 탭의 집중 띠(`spec.md` 6-1)는 돌아보기 화면에도 나옴(머리말 아래)

## 4. 돌아보기로 가는 길
| 출발 | 지금 | 바뀐 뒤 |
|---|---|---|
| 아래 탭 「돌아보기」 | 탭 | 없음 → 전체 탭 돌아보기 카드 |
| 결산 알림 | `?tab=look&recap=2026-11` | **`?tab=all&open=look&recap=2026-11`** → 전체 탭 위 돌아보기(결산 칸) 위에 결산 보기 바로. 뒤로 → 돌아보기 → 전체 |
| 주간 돌아보기 알림(일 21:00) | `?tab=look` | `?tab=all&open=look&view=week` |
| 연말 문답 입구 | 돌아보기 결산 칸 카드 | 전체 탭 돌아보기 카드 한 줄 + 돌아보기 결산 칸 카드(그대로) |
| 주간 퀘스트 카드(루틴 탭) | 돌아보기 탭으로 | 돌아보기 화면 「주」로(뒤로 → **루틴 탭**, 쌓인 곳으로) |
| 결산 「새로 나왔어요」 | 돌아보기 위 칸 | 전체 탭 카드 「새로」 + 아래 줄 |
- **이미 보낸 알림 · 홈 화면 바로가기의 옛 주소 `?tab=look…`도 그대로 열려야 해요** → `tab=look`을 받으면 `tab=all&open=look`으로 바꿔 처리(서비스워커 메시지 길 · 주소 길 둘 다)
- 서버 알림 주소(`recapNotify` · 돌아보기 알림)는 새 꼴로 바꿈 → **서버 다시 배포 필요**. 배포 전에 나간 알림은 위 바꾸기로 처리
- 알림 → 돌아보기 화면으로 바로(전체 탭을 먼저 보여 주지 않음)

## 5. 바뀌지 않는 것
- 루틴 · 시간표 · 할 일 화면 내용(집중 띠가 머리말 아래 생기는 것 말고)
- 머리말 칩 · 「우리 둘」 박스 · 단짝 기능 카드 · 설정 시트
- 돌아보기 「주 · 달 · 결산」 안의 화면 · 결산 카드 · 연말 문답 화면
