# 시험 — 집중 F1 · 탭 정리 · 테마 맞춤

> `npm test`에 넣을 자동 시험(A~D)과 손으로 볼 것(M). 고친 버그마다 회귀 시험 하나씩(가이드라인).
> 시간 계산 시험은 구현 뼈대(`focus/{uid}` · `focusLogs`) 모양에 맞춰 구현 계정이 입력 꼴을 정해요 — 아래는 **무엇을 확인할지**만.

## A. 탭 정리 (FT1)
| # | 확인 |
|---|---|
| A1 | `TABS` 순서 = routine · plan · **focus** · todo · all (id는 저장소 이름), `look` 없음 |
| A2 | 앱을 열면 루틴 탭. 저장된 마지막 탭이 `look`이면 `all`로 |
| A3 | `?tab=look` → 전체 탭 + 돌아보기 화면, `?tab=look&recap=2026-11` → 그 위 결산 보기 (옛 알림 주소) |

| A5 | 서비스워커 메시지 길로 같은 주소가 와도 A3 · A4와 같음 |
| A6 | 돌아보기 화면에서 뒤로(‹ · `popstate` · Esc) → 전체 탭, 스크롤 위치 그대로 |
| A7 | 루틴 탭 주간 퀘스트 카드 → 돌아보기 「주」, 뒤로 → 루틴 탭 |
| A8 | 전체 탭 블록 순서: 우리 둘 → 돌아보기 카드 → 단짝 기능(4칸, 순서 그대로) → 설정 |
| A9 | 돌아보기 카드 아래 줄: 11-25 「12월 1일 아침에 11월 결산이 나와요 · …」 / 12-03(결산 있음) 「11월 결산이 나왔어요 ›」 + 「새로」 / 12-10 연말 문답 줄 있음 / 02-01 연말 문답 줄 없음 (날짜를 넣어 시험) |
| A10 | 320px에서 탭 글자 다섯 개가 한 줄(`scrollWidth <= clientWidth`) |

## B. 테마 · 색 (FT2)
| # | 확인 |
|---|---|
| B1 | `tokens.css`에 `--focus-ring` · `--focus-track`이 `[data-theme]` 기본으로 있고, 테마 블록 안에는 Cosmic Dream 말고 없음 |
| B2 | 대비 계산 함수(WCAG 2.x 상대 휘도, 저장소에 이미 있으면 그것)로 **`contrast.md` 쌍 목록 P1~P12(4.5:1) · G1~G2(3:1)** 를 모든 판에서 계산 — 하나라도 미만이면 실패. `var()`는 끝까지 풀어서 |
| B3 | B2를 58판 전부(기본 14 + 도트 44)로 돌림 — 기획 계정이 v84 값으로 미리 계산한 결과는 모두 통과(`contrast.md`). 저장소 값이 그 뒤에 바뀌어 3:1 미만이 생기면 그 판만 `--focus-ring: var(--tab-active)` 한 줄 + 다시 계산하고 「바뀐 것」에 |
| B4 | 도트 22테마 S3: 집중 화면 배율 = 할 일 탭 배율, 높이 > 140px이면 배율 −1, 결과가 정수 배율 · 1 이상 |
| B5 | 새 화면 CSS · JS에 색 글자(`#…` · `rgb(`) 없음 — 토큰만 (그림 파일 · `head/bg` SVG는 예외 그대로) |
| B6 | 도트가 아닌 테마로 집중 탭 · 집중 화면을 열었을 때 Galmuri · `pixel.css` · 테마 그림 요청 0건 |
| B7 | 픽셀 계단 링: 진행 0 → 진행 칸 0개, 진행 0.5 → 링 칸의 절반 ±1칸, 진행 1 → 전부. 외곽선 칸은 진행과 상관없이 같은 수 |

## C. 집중 화면 (FC1)
| # | 확인 |
|---|---|
| C1 | 시간 꼴: 0초 → `0:00:00`, 59분 59초 → `0:59:59`, 3시간 20분 15초 → `3:20:15`, 칩 `1:05`, 분 표시 「48분」 / 60분부터 `1:00` |
| C2 | 하루 경계: 04:30~05:30 집중 1시간 → 어제 30분 + 오늘 30분 (Asia/Seoul) |
| C3 | 주 경계: 월요일 04:59 기록은 지난주, 05:00부터 이번 주 |
| C4 | 함께 시간 = 두 사람 기록이 겹친 구간 합. 쉬기 · 자리 비움 구간은 빼고 계산. 겹침이 여러 조각이어도 합이 맞음 |
| C5 | 어제와 비교: 많으면 「어제보다 +40분」, 같거나 적으면 「어제 4:00」, 어제 0이면 빈 글 |
| C6 | 상태 → 짝꿍 카드 버튼: 쉬는 중 · 오늘 안 함 → 같이 하자 / 집중 중 → 같이 하기 / 둘 다 · 자리 비움 · 잠깐 쉬는 중 → 없음 / 보낸 뒤 30분 → 보냈어요(꺼짐) |
| C7 | 띠: 짝꿍만 · 나만 · 둘 다 · 나 쉬는 중 → 문구 4가지 (`spec.md` 6-1 표 그대로), 짝꿍 쉬는 중 · 자리 비움 · 아무도 → 띠 없음 |
| C8 | 탭 점: 짝꿍만 `[her]` · 나만 `[me]` · 둘 다 `[me, her]` · 집중 탭에 있을 때 `[]` · 자리 비움 `[]` |
| C9 | 엄격: 앱을 나가고 5초 안에 돌아오면 그대로 집중 중 / 5초 넘으면 자리 비움, 나가 있던 시간은 빠짐, 「다시 시작」 뒤 이어서 셈 |
| C10 | 짝꿍에게 보이는 자리 비움은 「잠깐 자리 비움」 글 하나 — 횟수 · 시간 · 알림 없음, 띠 없음 |
| C11 | 3시간 → 「아직 하고 있어요?」 한 번만, 「네」 뒤 다시 안 물음 |
| C12 | 서버가 닫은 기록 → 다음에 열 때 「언제 끝났어요?」 한 번. 「마지막으로 앱을 본 01:42」가 기본, 고른 끝 시각으로 시간 · 함께 시간 다시 계산, 「기록하지 않을래요」 → 기록 없음 |
| C13 | 기록 고치기: 끝 < 시작 · 지금보다 늦음 · 다른 기록과 겹침이면 저장 안 됨, 짝꿍 기록은 고치기 버튼 없음 |
| C14 | 1분 미만 기록은 저장 안 됨 + 토스트 |
| C15 | 시작 시각 기준 계산: 앱을 닫았다 30분 뒤 열면 숫자가 30분 늘어 있음(타이머 누적 아님) |
| C16 | 과목 시트: 카테고리 16개까지 · 짧은 이름 8자 넘으면 더 못 씀 · 최근 짧은 이름 5개 · 「같이 하기」로 열면 내 마지막 과목 |
| C17 | 큰 글씨: 문서 글자 130%에서 큰 숫자가 한 줄(`scrollWidth <= clientWidth`) |

## D. 문구
| # | 확인 |
|---|---|
| D1 | `spec.md` 8절 문구가 한 모듈(예: `js/focus-text.js`)에만 있음 — 화면 코드에 한글 문장 없음 (출출 쿠키 `eat-text.js`와 같은 방식) |
| D2 | 짝꿍 이름 조사: 「다진 님이」 · 「준민 님이」처럼 「님」 뒤라 받침 상관없이 「이」 — 카드 · 띠에서는 이름만 |
