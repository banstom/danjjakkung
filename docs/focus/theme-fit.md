## 1. 한 줄로
**테마마다 따로 고칠 값은 Cosmic Dream 한 줄뿐이에요.** 새 화면은 기존 토큰 + 새 토큰 2개(둘 다 기존 토큰을 가리킴)로 그려지고, 도트 테마 22개는 같은 도트 부품 + 테마의 S3 그림을 써요.

| 띠 | 1.5px 사람 색 테두리 | 3px `--ol` 외곽선 + 왼쪽 안쪽 6px 사람 색 |

## 4. 그림 자리 다시 보기
| 자리 | 결론 |
|---|---|
| **S1** 머리말 오른쪽 | 집중 탭 머리말에서는 **그리지 않음**(오른쪽에 ⚙ 알약). 다른 탭은 그대로. 머리 장식과는 겹치지 않음 — 머리말이 장식 높이만큼 내려와 있어서(`ws-02` · `cin-02`) |
| S2 출출 쿠키 입구 | 바뀌지 않음 |
| **S3** 할 일 다 끝냄 | **집중 화면 · 끝냄 요약에도 씀**(사용자 결정). 할 일 탭 자리는 그대로 |
| **S4** 결산 표지 | **그대로.** 결산 보기는 전체 탭 › 돌아보기에서 열려도 같은 전체 화면 보기라 바뀔 것 없음 |
| S5 (새 자리) | **만들지 않음** — 새 그림 0장, `prompts.md` 없음, `design/assets/themes/` 새 파일 없음 |
| 머리 장식 · 바탕 무늬 | 집중 탭 · 집중 화면 · 전체 탭 모두 다른 탭과 같은 파일 |

### S3 크기 규칙
- 할 일 탭과 같은 정수 배율. 집중 화면 칸 높이 140px — 넘으면 한 단계 낮은 정수 배율. 끝냄 요약은 높이 제한 없음
- 화면 높이 700px 미만이면 집중 화면에서만 숨김(끝냄 요약은 보임)
- 기획 문서에 크기가 남아 있는 것: 겨울 간식 120×93 · 크리스마스 84×123 · 천문대 120×123 · 기차 132×80 · 영화관 108×92 → 모두 140px 안. 나머지는 저장소 `themes.js`의 S3 배율로 B4 시험이 확인

## 6. 테마를 바꿔도 안 바뀌어야 하는 것 (점검 AI 확인용)
- 루틴 · 시간표 · 할 일 화면: 띠 말고 픽셀 하나도 안 바뀜(머리말 아래 띠가 없을 때 바뀌기 전과 같은 스크린숏)
- 도트가 아닌 테마에서 Galmuri · 테마 그림 · `pixel.css`를 내려받지 않음(지금 규칙 그대로)
- S3는 정수 배율로만 그려짐(`image-rendering: pixelated`, 크기 = 원본 × 정수)
- 색은 토큰만(SVG 그림 파일 · 링 SVG의 `style="fill:var(--…)"` 포함)
