# 집중 통계 새 토큰 (기획 계정, 2026-11-26)

> **테마마다 값을 새로 적지 않아요.** 모두 지금 있는 토큰에서 `color-mix()`로 만들어요. 그래서 58판(기본 14 + 도트 44) 어디에든 바로 그려지고, 대비 시험에서 걸린 판만 그 판에 값을 덮어쓰면 돼요.
> 목업의 테마 값(soft-pastel · midnight-noir · winter-snack)은 **근사값**이에요. 아래 대비 숫자도 목업 값으로 잰 것 → 저장소 실제 값으로 대비 시험을 꼭 다시.

## 1. 토큰

정의 자리: 집중 통계를 그리는 카드들의 바깥(`.fs-card`, 돌아보기 집중 카드, 결산 집중 카드) — 또는 테마 토큰이 정해지는 `html[data-theme]`과 **같은 요소**. `:root`에만 두면 테마가 `html[data-theme=…]`에서 `--me`를 바꿀 때 안 따라올 수 있어요(같은 요소면 따라옴).

| 토큰 | 값 (식) | 쓰는 곳 |
|---|---|---|
| `--focus-ring` | `var(--strong)` (코스믹 드림 `var(--accent)`) | **있음(11-25)** — 고른 날 테두리 · 버튼 초점 |
| `--focus-track` | `var(--empty)` | **있음(11-25)** — 빈 칸 · 띠 바탕 · 과목 막대 바탕 · 0단계 |
| `--fm-1` | `color-mix(in srgb, var(--me) 35%, var(--focus-track))` | 나 1단계 (1분+) |
| `--fm-2` | `color-mix(in srgb, var(--me) 75%, var(--focus-track))` | 나 2단계 (1시간+) |
| `--fm-3` | `var(--me)` | 나 3단계 (2시간+) |
| `--fm-4` | `color-mix(in srgb, var(--me) 45%, var(--text))` | 나 4단계 (4시간+) — 밝은 판은 짙게, 어두운 판은 밝게 |
| `--fh-1` ~ `--fh-4` | 위와 같은 식, `--her` | 짝꿍 단계 |
| `--fb-1` ~ `--fb-4` | 위와 같은 식, `--both` | 결산 「함께」 작은 달력 (함께 단계 1분 · 30분 · 1시간 · 2시간) |
| `--focus-goal` | `var(--sub)` | 목표선 |
| `--focus-num` | `var(--text)`, **어두운 판(cosmic-dream · midnight-noir · 도트 밤 판)은 `var(--card)`** | 2 · 3단계 칸 위 날짜 숫자 |

- 4단계 칸 위 숫자 = `var(--card)`, 0 · 1단계 칸 위 숫자 = `var(--text)`
- 함께한 날 점 = `var(--both)` + 2px `var(--card)` 테두리(칸 위에 올라가도 떨어져 보이게)
- 오늘 칸 = 안쪽 2px `var(--text)` (도트 4px), 아직 안 온 날 = 바탕 없이 1px `var(--line)` (도트 2px)

`color-mix()`: iOS Safari 16.2+ · Chrome 111+. 더 옛 기기에서 빈 칸으로 보이지 않게 앞에 대신 값을 한 줄 두기:
```css
--fm-1: var(--me);            /* color-mix 못 읽는 브라우저 */
--fm-1: color-mix(in srgb, var(--me) 35%, var(--focus-track));
```

## 2. 대비 시험에 더할 쌍 (`contrast` 시험, 58판 전부)

| 쌍 | 기준 | 뜻 |
|---|---|---|
| `--fm-4` / `--card`, `--fh-4` / `--card` | **3:1** | 가장 진한 칸이 카드 바탕에서 보임 |
| `--fb-4` / `--tint` | **3:1** | 결산 달력 |
| `--text` / `--fm-1`, `--fh-1` | **4.5:1** | 1단계 칸 위 날짜 숫자 |
| `--focus-num` / `--fm-2`, `--fm-3`, `--fh-2`, `--fh-3` | **4.5:1** | 2 · 3단계 칸 위 날짜 숫자 |
| `--card` / `--fm-4`, `--fh-4` | **4.5:1** | 4단계 칸 위 날짜 숫자 |
| `--sub` / `--card` | 4.5:1 | 목표선 글자 · 눈금 (이미 있는 쌍) |

- 걸리면: 그 판에만 `--fm-4` · `--focus-num` 같은 토큰을 덮어쓰기. 식을 바꾸지 말기
- 1단계와 바탕(`--focus-track`)의 차이는 기준 없음 — 진하기는 날짜 숫자 · 한 줄 · 기록 칸 숫자로도 읽히므로 색만으로 뜻을 전하지 않음

### 목업 근사값으로 잰 것 (참고)
| 판 (근사값) | 4단계/card (나 · 다진) | text/1단계 | focus-num/2단계 | focus-num/3단계 |
|---|---|---|---|---|
| soft-pastel | 4.8 · 4.6 | 8.5 · 8.7 | 7.1 · 7.5 | 6.3 · 6.8 |
| midnight-noir (`--focus-num` = card) | 10.8 · 11.3 | 6.5 · 6.1 | 4.8 · 5.2 | 7.1 · 7.8 |
| winter-snack 낮 | 5.8 · 6.1 | 8.1 · 8.0 | 6.2 · 6.0 | 5.3 · 5.1 |

- 「card/4단계 숫자」는 4단계/card와 같은 값
- 파스텔 판은 2 · 3단계 색 차이가 작아요(예: 다진 2 · 3단계). 진하기는 덧붙이는 정보라 그대로 두되, 실제 값에서 너무 비슷하면 그 판만 `--fh-2`를 60%로 덮어쓰기
