## 한 줄씩
- **집중 탭** = 이번 주 「지금」: 막대 + 목표선, 지난주 **이맘때**보다 늘었을 때만 칩, 요일을 누르면 **시간대 띠**, 과목은 한 색 순위 막대, 기록 칸(연속 · 가장 긴 한 번 · 목표 채운 날)
- **돌아보기** = 그 기간 「돌아보기」: 큰 숫자 함께, 비교 없음, 주 = 진하기 7칸 두 줄, 달 = 달력(「나 | 다진」) + 함께한 날 점
- **결산** = 「자랑하기」: 「함께 집중」 카드를 함께 보낸 시간 다음에, **12-01(11월 결산)부터**. 11월은 「11/25부터 모은 기록이에요」, 막히면 `FOCUS_CARD_ON = false`로 12월부터
- 짝꿍 과목은 통계 어디에도 안 나옴. 띠로 짝꿍이 **언제** 했는지는 보임(사용자 확인함)
- 읽기: 집중 탭은 지난 4주를 한 번 더 읽음(색인 · 실시간 구독 추가 없음)
