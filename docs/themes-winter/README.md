# 겨울 업데이트 테마 — 구현 계정용 안내

> 기획 계정(claude.ai)에서 2026-11-19에 만든 묶음이에요. 기획 계정의 대화 · 프로젝트 · 아티팩트는 이 계정에서 볼 수 없으니 **이 폴더가 기준**이에요.

## 1. 무엇을 하나
도트(픽셀) 테마 두 개를 더해요 — 「도란도란 겨울 간식」, 「두근두근 크리스마스」. 둘 다 낮 · 밤 판이 있고, 테마 설정에 「자동 · 낮 · 밤」이 생겨요. 1년 내내 고를 수 있어요.

## 2. 읽는 순서
1. `spec.md` — 명세 (기준)
2. `design/mockups/chosen/themes-winter/screens/` 11장 — 화면 그림 (`index.html`은 같은 화면을 한 페이지에, 브라우저로 열기)
3. `tokens-draft.css` — 네 판 색 토큰 전부 (→ `styles/tokens.css`)
4. `pixel-skin-draft.css` — 픽셀 스킨 CSS 초안 (클래스 이름은 실제 코드에 맞게)
5. `tests.md` — 시험 목록
6. `contrast.md` — 글자 대비 계산표
7. `HANDOFF.md` — 그림을 다시 받을 때 쓰는 프롬프트 · 처리 순서 (지금은 안 읽어도 됨)

그림 · 장식 파일: `design/assets/themes/{winter-snack,merry-xmas}/` — `s1~s4.png`, `bg.svg` `bg-night.svg` `head.svg` `head-night.svg`. 빌드에서 `/themes/…`로 나가게 (앱의 정적 파일 위치에 맞춰 경로 조정)

## 3. 단계 (한 단계 = 한 브랜치, 끝날 때마다 npm test 통과 + 점검)
| 단계 | 브랜치 | 내용 | 시험 |
|---|---|---|---|
| **W1** | `winter-w1` | 토큰 네 판 + `themes.js` 판 묶음(`modes`) + 모드 저장(`danjjakkung.themeMode`) + 판 고르기 + `<head>` 깜빡임 방지 스크립트. **화면 모양은 아직 그대로**(색만 바뀜) | A1~A4, B1~B9 |
| **W2** | `winter-w2` | 픽셀 스킨: `data-skin` 켜고 끄기, 카드 · 버튼 · 점선 · 세그먼트 · 탭, 머리 장식 · 바탕, Galmuri(도트 테마일 때만) + 글씨 크기 표 확정 | C1~C6 |
| **W3** | `winter-w3` | 그림 자리 S1~S3 (머리말 · 짝꿍 식탁 카드 · 빈 화면), 정수 배율. S4는 결산 화면이 있으면 연결, 없으면 자리 부품만 | D1~D5 |
| **W4** | `winter-w4` | 테마 설정 화면 「테마·사람 색」 (자동 · 낮 · 밤, 테마 카드 미리보기, 사람 색) | E1~E5 |
| **W5** | — | 점검 AI → 고치기 → 폰에서 목업 대조 → main → 배포 | 전체 |

- 가이드라인 예외 4가지(spec.md 8절)는 W1에서 저장소 가이드라인 문서에 먼저 적어 주세요
- 목업에 없는 화면 · 문구가 필요하면 만들지 말고 `## 바뀐 것`에 질문으로 남기기 → 기획 계정에서 목업

## 4. 문서와 다르게 정하면
`spec.md` 맨 아래 `## 바뀐 것`에 한 줄씩 (날짜 · 무엇을 · 왜). 단계가 끝날 때 사용자가 기획 계정으로 옮겨요.
