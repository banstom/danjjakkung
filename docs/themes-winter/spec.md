## 1. 무엇을 넣나
| 이름(화면) | 낮 판 id | 밤 판 id | 꼬리표 |
|---|---|---|---|
| 도란도란 겨울 간식 | `winter-snack` | `winter-snack-night` | `낮·밤` `NEW` |
| 두근두근 크리스마스 | `merry-xmas` | `merry-xmas-night` | `낮·밤` `NEW` |

- **1년 내내 고를 수 있어요.** 계절 한정 아님 (겨울에 맞춰 내놓을 뿐)
- 두 테마 모두 **픽셀 스킨**(`data-skin="pixel"`)을 써요: 도트 글꼴 · 픽셀 테두리 카드 · 게임 버튼 · 점선 구분선 · 머리 장식 · 바탕 무늬 · 그림 4장
- 다른 테마(소프트 파스텔 등)는 아무것도 바뀌지 않아요. 픽셀 스킨 CSS는 `[data-skin="pixel"]` 아래에만

## 2. 테마 목록 · 낮밤 판 (themes.js)
- 테마 목록 항목에 **판 묶음** 필드를 더해요 (이름은 구현에 맞게):
```js
{ id: 'winter-snack', name: '도란도란 겨울 간식', skin: 'pixel', modes: { light: 'winter-snack', dark: 'winter-snack-night' }, tags: ['NEW'] },
{ id: 'merry-xmas',   name: '두근두근 크리스마스', skin: 'pixel', modes: { light: 'merry-xmas',   dark: 'merry-xmas-night' },   tags: ['NEW'] },
```
- 고른 테마는 지금처럼 `danjjakkung.theme`(localStorage)에 **묶음 id**(`winter-snack`)로 저장. 판 id(`-night`)는 저장하지 않음
- **새 설정 `danjjakkung.themeMode` = `auto` | `light` | `dark`, 기본 `auto`**
- 실제로 그릴 판: `modes`가 있는 테마면 `mode==='auto' ? (시스템 다크 ? dark : light) : mode` → `<html data-theme="<판 id>" data-skin="pixel">`
- `auto`일 때 `matchMedia('(prefers-color-scheme: dark)')`의 change를 들어서 **켜 둔 채로 바로** 바뀌어야 해요
- `modes`가 없는 테마는 지금 그대로(모드 값 무시). 테마를 아직 안 고른 사람도 지금 그대로(밝게 `soft-pastel` / 어둡게 `cosmic-dream`)
- **첫 화면 깜빡임 방지**: `<head>`의 짧은 인라인 스크립트에서 두 값을 읽어 `data-theme` · `data-skin`을 먼저 붙인 뒤 화면을 그려요 (앱 회귀 테스트 9번 '첫 프레임' 검사와 같은 방식으로 확인)
- 저장된 테마 id가 목록에 없으면 기본 테마로 (옛 '발자국' 테마 회귀 10번과 같은 규칙). `-night`가 붙은 id가 저장돼 있으면 묶음 id로 고쳐 저장
- 사람마다 기기별 저장(짝꿍과 공유 안 함) — 지금 테마와 같은 곳

## 3. 색 토큰
- `tokens-draft.css`: 네 판 × 기존 토큰 47개 + 새 토큰 7개를 모두 채움 → `styles/tokens.css`에 붙이기
- 새 토큰 (다른 테마에도 값이 필요하면 `--ol: var(--line)` 같은 기본값을 공통 블록에)
| 토큰 | 뜻 |
|---|---|
| `--ol` | 픽셀 외곽선 |
| `--sh` | 각진 그림자 |
| `--btn-hi` / `--btn-lo` | 버튼 안쪽 위 밝은 줄 / 아래 어두운 줄 |
| `--sec-dot` | 섹션 제목 앞 작은 점 |
| `--deco-a` / `--deco-b` | 장식 두 색 (그림 SVG 안의 색과 같은 값, 기록용) |
- 글자 대비: `contrast.md` — 21쌍 × 4판 모두 4.5:1 이상
- **빨강**: 경고는 계속 `--warn`만. 차양 · 가랜드 방울 · 섹션 점의 빨강은 **장식 그림**으로 취급(가이드라인 예외, 6절)

## 4. 글꼴 — Galmuri (픽셀 스킨에서만)
- [Galmuri](https://github.com/quiple/galmuri) (SIL OFL 1.1) — 처음부터 도트로 그린 한글 글꼴. 구현 계정에서 받아 `design/assets/fonts/galmuri/`에 넣기
- **픽셀 스킨일 때만** 불러와요 (다른 테마 사용자는 내려받지 않음). `font-display: swap`, 한글 전체라 크면 자주 쓰는 글자 subset 검토
- 도트 글꼴은 **고유 크기의 정수배에서만 선명**해요. 목업은 시험용 글꼴로 12px 격자(12 · 24px)와 16px 격자(16px)를 썼어요. Galmuri는 판마다 고유 크기가 달라서, README의 권장 크기로 아래 표를 확정해 주세요
| 쓰임 | 목업 | Galmuri 안 (확정 필요) |
|---|---|---|
| 작은 글씨(날짜 · 탭 · 보조 문구 · 꼬리표) | 12px | Galmuri11, 고유 크기 |
| 본문 · 목록 · 카드 이름 · 버튼 | 16px | Galmuri14, 고유 크기 |
| 화면 제목 · 결산 표지 제목 | 24px | Galmuri11 × 2 |
- 굵게: Galmuri11 Bold. Galmuri14에 Bold가 없으면 굵게 대신 크기 · 색으로 위계
- 원래 크기 토큰(`--fs-*`)을 픽셀 스킨에서만 위 값으로 덮어써요. 13px → 작은 글씨, 20px → 제목으로 옮김
- 숫자 · 영문도 Galmuri로 (목업의 D+314, 2026년 11월)
- 앱 정보 화면에 「Galmuri 글꼴 사용 (SIL OFL)」 한 줄 추가

## 5. 장식 · 바탕 · 부품 (pixel-skin-draft.css)
- **머리 장식**: 화면 맨 위 가로 띠 — `head.svg`(16칸 타일을 3배 = 48px 간격) 가로 반복
  - 도란도란: 빨강 · 크림 줄무늬 차양 + 계단 물결 (높이 42px) / 밤: 조금 어두운 차양 + 전선과 노랑 · 주황 전구 (60px)
  - 두근두근: 솔잎 가랜드 + 빨강 · 금색 방울 (42px) / 밤: + 알록달록 전구 줄 (60px)
  - 머리말은 장식 높이만큼 아래로 (목업: 낮 40px, 밤 56px 여백)
- **바탕**: 24px 옅은 체크 + `bg.svg` 무늬(반짝이 · 별 · 눈송이) 반복
- **카드**: 모서리 0, 3px 외곽선을 box-shadow 네 방향으로(모서리 한 칸이 파여 둥글게 보임) + 아래 각진 그림자
- **버튼**: 같은 외곽선 + 안쪽 위 `--btn-hi` · 아래 `--btn-lo` 줄. 눌렀을 때 2px 내려감
- **목록 구분선**: 6px 간격 픽셀 점선
- **세그먼트**: 픽셀 테두리 상자, 칸 사이 3px 선, 고른 칸은 메인 색 + 버튼 줄
- **아래 탭**: 위 3px 외곽선, 고른 탭은 `--tint` 상자 + 테두리(밤은 `--btn-lo` 테두리). 아이콘은 **같은 선 SVG**를 끝만 각지게(square/miter) — 토스페이스 · 아이콘 모양은 그대로
- 그림 SVG 안의 색은 고정 hex예요(판마다 파일이 따로). 색 하드코딩 검사 테스트에서 `themes/**/*.svg`는 그림 파일로 빼 주세요

## 6. 그림 4장 (S1~S4)
| 자리 | 어디 | 도란도란 | 두근두근 | 배율 |
|---|---|---|---|---|
| S1 | 머리말 오른쪽 | 군밤 봉지 (38×38) | 작은 트리 (32×40) | 2배 |
| S2 | 「전체」 짝꿍 식탁 카드 가운데 | 붕어빵 둘 (34×34) | 진저브레드 둘 (37×38) | 2배 |
| S3 | 빈 화면(할 일을 다 끝냈을 때 등) | 군고구마 (40×31) | 눈사람 (28×41) | 3배 |
| S4 | 월말 · 연말결산 표지 | 간식 한 상 (64×65) | 선물 더미 (40×40) | 도란도란 2배 · 두근두근 3배 |
- 파일: `design/assets/themes/<테마>/s1~s4.png` (크기는 크림색 1칸 테두리 포함, 원본 1배 PNG). **낮 · 밤 판이 같은 그림**을 써요
- 화면에는 `width = 원본 × 배율`, `image-rendering: pixelated`. **정수 배율만** (1.5배 등 금지 — 칸이 들쭉날쭉해짐)
- 그림이 있는 테마에서만 자리를 그려요. 다른 테마는 지금 화면 그대로(자리 없음)
- 고른 테마의 그림만 불러옴. 합계: 도란도란 ≈ 12KB, 두근두근 ≈ 8.7KB (상한 150KB)
- `alt`: S1 「군밤 봉지」/「작은 트리」, S2 「붕어빵 두 마리」/「진저브레드 쿠키 둘」, S3 「김 나는 군고구마」/「눈사람」, S4 「간식 한 상」/「선물 더미」. 장식뿐인 자리는 `alt=""`도 가능 — 구현에서 판단
- 결산 화면이 아직 없으면 S4는 결산을 만들 때 연결 (결산 표지 문구: 월말 「2026년 11월」 + 「이번 달의 단짝꿍」, 연말 「2026년」 + 「이번 해의 단짝꿍」)

## 7. 테마 설정 화면 「테마·사람 색」
- 들어가는 곳: 「전체」 탭 > 설정 > 테마·사람 색 (지금 머리말 🎨 `open-theme` 시트가 있으면 같은 화면으로 바꾸거나 시트 안에 같은 내용 — 지금 코드에 맞춰 정하고 `바뀐 것`에 남기기)
- 위에서부터
  1. **낮 · 밤** — 세 칸 「자동 · 낮 · 밤」(기본 자동) + 아래 한 줄
     - 자동: 「지금은 낮이에요 · 휴대폰 설정을 따라요」 / 「지금은 밤이에요 · 휴대폰 설정을 따라요」
     - 낮 · 밤으로 고정: 「늘 낮으로 보여요」 / 「늘 밤으로 보여요」 (목업에 없는 문구 — 가정)
     - **고른 테마에 `modes`가 없으면 이 줄 전체를 숨기고** 테마 제목 아래 「이 테마는 한 가지 밝기만 있어서 낮·밤 고르기가 없어요」
  2. **테마** — 2열 카드: 작은 미리보기(그림 없이 CSS: 바탕색 · 머리 장식 색 띠 · 작은 카드 · 메인 색 막대) + 이름 + 꼬리표(`사용 중` `낮·밤` `NEW` `밝게` `어둡게`). 고른 카드는 메인 색 테두리. 이름은 `word-break: keep-all`(「두근두근 / 크리스마스」)
     - 미리보기는 지금 판(낮/밤)에 맞춰 그 테마의 낮 · 밤 색으로
  3. 「다른 테마 더 보기」 — 나머지 테마 (기존 목록)
  4. **사람 색** — 나 · 짝꿍 (기존 기능 그대로)
- 이 화면도 고른 테마로 그려져요 (도트 테마면 도트 글꼴 · 픽셀 카드)
- 테마 · 모드를 바꾸면 바로 화면 전체에 적용 (저장 버튼 없음)

## 8. 가이드라인 예외 (저장소 가이드라인에 덧붙이기)
1. **테마 그림**: 정해진 자리 S1~S4에 한해 그림 AI(Gemini)로 만든 도트 그림을 써요. 아이콘 · 버튼 · 상태 표시는 계속 토스페이스와 선 SVG
2. **글꼴**: 픽셀 스킨 테마에서만 Galmuri. 그 밖은 계속 프리텐다드 하나
3. **장식 빨강**: 머리 장식 · 섹션 점의 빨강은 장식 그림. UI 의미(경고)는 `--warn`만
4. **색 하드코딩**: 그림 파일(`themes/**/*.svg`, PNG) 안의 색은 검사에서 뺌. CSS · JS의 색은 계속 토큰만
