## 0. 한 줄 요약
- 「전체」 탭 › 우리 기능 › **단짝 영수증**. 함께 쓴 돈만 적고, 누가 냈는지 남겨요.
- 정산(송금)은 하지 않아요. **비율과 금액**, **요약 한 줄**("이번 달은 단짝이 3,800원 더 냈어요")만 보여 줘요.
- 적기는 **한 줄 말투**(`숙소 12만 반반`)를 앱 코드로 읽어요. AI를 쓰지 않아요.
- 나눠 낸 돈은 **B · 한 줄 나눔**: 한 기록에 두 사람 몫(`shares`)을 함께 저장해요.

### L3 ~ L6 한 줄 적기 (바텀 시트)
- 제목 「한 줄 적기」, 설명 「평소 말투로 · 저녁 42000 내가 · 숙소 12만 반반」
- 입력칸(라벨 「무엇을 얼마에, 누가」) — **입력할 때마다** `parseLine`으로 읽어서 아래 칸을 채워요(디바운스 없이 해도 됨, 계산이 가벼움)
- 날짜 알약 「오늘 · 11월 19일 (목)」 — 누르면 날짜 고르기. 한 줄에 `어제` `그저께` `15일` `11/15`가 있으면 그 날로
- 「누가 냈나요」 3칸: 나 · 단짝 · 둘이 나눔
- 둘이 나눔이면 **몫 상자**(L3 · L4): 무엇 + 합계, 몫 막대, 사람별 금액 칸 두 개. 한쪽을 고치면 다른 쪽 = 합계 − 고친 값(`rebalance`)
  - `내가 12000 단짝 11000`처럼 각자 적었으면 그 값으로 채우고 안내 「…을 각자 몫으로 읽었어요」(L4)
- 혼자 낸 것이면 읽은 값 상자(무엇 + 금액)만
- 「분류」 칩 7개: 식사 · 카페 · 교통 · 숙소 · 놀거리 · 장보기 · 기타
- **한 번 더 봐 주세요 (L5)**: `payerGuessed` → 누가 칸 테두리 `--accent` + 「누가 냈는지 안 적혀서 준민(적는 사람)으로 해 뒀어요」 / `catGuessed=false` → 기타 칩 점선 + 「분류를 못 찾아서 기타로 해 뒀어요 · 눌러서 바꿔요」. 사용자가 그 칸을 누르면 강조가 풀려요. 저장은 막지 않아요
- **금액 못 찾음 (L6)**: 입력칸 테두리 `--warn` + 「금액을 못 찾았어요 · 예: 42000 · 4.2만 · 4만2천」, 저장 비활성. `too-big`이면 「1억 원보다 작게 적어 주세요」
- 사용자가 아래 칸(누가 · 분류 · 몫 · 날짜)을 직접 고친 뒤에 한 줄을 또 고치면, **직접 고친 칸은 덮어쓰지 않아요**
- 저장 → 시트 닫힘 → 토스트 「적었어요」 + 목록 맨 위에 새 줄. 단짝에게 알림은 **보내지 않아요**(가정 — 자주 적는 기능이라 알림이 많아짐)

### L7 고치기 · L8 지우기 확인

## 3. 한 줄 읽기 규칙 (`parseLine`, 참조 구현 그대로)
띄어쓰기로 낱말을 나눈 뒤 **날짜 → 금액 → 누가** 순서로 낱말을 가져가고, 남은 낱말이 「무엇」이에요.

| 무엇 | 규칙 | 예 |
|---|---|---|
| 금액 | 낱말 **전체**가 금액 모양일 때만. 숫자(쉼표 · 소수) + 억/만/천 + 원, 한글 수(오만 · 만오천 · 삼천오백원). 단위 없는 맨 숫자는 100 이상만 | `42,000원` `5.98만` `12만5천` `오만원` / 아님: `천안` `2인` `7번` `3` |
| 띄어 쓴 금액 | `12만` 바로 뒤 낱말이 1만 미만 금액이면 더함 | `12만 5천` → 125,000 |
| 금액 여러 개 | 마지막 것 (각자 몫으로 읽힌 경우 제외) | `2만 깎아서 저녁 4만` → 40,000 |
| 누가 | 나: 내가 · 나 · 내 · 제가 · 저 · 내 이름 / 단짝: 단짝 · 너 · 니가 · 네가 · 자기 · 단짝 이름 / 둘이: 반반 · 나눠 · 나눔 · 둘이 · 같이 · 더치(페이) · n빵 · 엔빵 · 1/n. 조사(이 · 가 · 이가 · 는 · 은 · 님)는 떼고 봄 | `준민이` `단짝이가` |
| 각자 몫 | 금액이 둘 이상이고, 사람 낱말이 금액 **바로 앞**(먼저 봄) 또는 **바로 뒤**에 붙어 나 · 단짝이 모두 나오면 → 둘이 나눔 + 그 몫 | `내가 12000 단짝 11000` `7만 내가 5만 단짝` |
| 반반 | 홀수면 남는 1원은 **적는 사람** 몫 | 13,701 → 6,851 / 6,850 |
| 누가 없음 | 적는 사람, `payerGuessed: true` | |
| 날짜 | 오늘 · 어제 · 그제 · 그저께 · `N일`(오늘보다 뒤면 지난달) · `M/D` · `M.D` | `25일`(11-19에) → 10-25 |
| 분류 | 낱말 목록, 카페 → 숙소 → 교통 → 놀거리 → 장보기 → 식사 순서로 먼저 맞는 것. **한 글자 낱말(밥 · 회 · 술)은 낱말 전체일 때만**. 못 찾으면 기타 + `catGuessed: false` | `브런치 카페` → 카페, `회사 근처` → 기타 |
| 무엇이 빔 | 분류 이름 | `42000 내가` → 기타 |
| 오류 | 금액 없음 `no-amount`, 1억 이상 `too-big` | |

- 원문(`raw`)은 앞뒤 공백만 지우고 그대로 저장. 무엇의 대소문자도 그대로(`KTX`)
- 이름 낱말은 `users/{uid}.nickname` 두 사람 것을 씀. 이름이 「나」 「단짝」처럼 예약 낱말과 같아도 위 표 순서대로

## 4. 데이터

```
couples/{coupleId}/spends/{spendId}     ← 다른 커플 기능과 같은 자리 (저장소의 실제 경로를 따름)
{
  date: "YYYY-MM-DD",           // 쓴 날 (서울 기준)
  amount: number,               // 정수 원, 1 ~ 99,999,999
  paidBy: <uid> | "both",
  shares?: { <uid>: number, <uid>: number },   // paidBy가 both일 때만, 두 값 합 = amount, 둘 다 1 이상
  what: string,                 // 1~40자
  cat: "meal"|"cafe"|"move"|"stay"|"play"|"shop"|"etc",
  raw?: string,                 // 적은 한 줄 (0~80자)
  createdAt, createdBy, updatedAt, updatedBy
}
```
- 저장 직전 `normalizeShares`: 몫 한쪽이 0이면 그 사람이 다 낸 것으로 바꿔 `paidBy: <uid>`로, `shares`는 지움
- 화면 쪽 `me/partner` ↔ 저장 쪽 uid 바꾸기는 저장 직전 한 곳에서만
- 읽기: 보고 있는 달만 `where date >= 'YYYY-MM-01' and date <= 'YYYY-MM-31'`(문자열 비교) + `orderBy date desc`. 이번 달만 `onSnapshot`, 지난달은 한 번 읽기. 단일 필드 색인이라 색인 추가 없음
- 전체 탭 카드(L11)는 이번 달 구독을 같이 써요(따로 읽지 않음)

### `firestore.rules` (요지)
```
match /couples/{cid}/spends/{sid} {
  allow read, delete: if isMember(cid);
  allow create, update: if isMember(cid) && validSpend(request.resource.data)
                        && request.resource.data.updatedBy == request.auth.uid;
}
function validSpend(d) {
  return d.amount is int && d.amount >= 1 && d.amount < 100000000
    && d.date is string && d.date.matches('^\\d{4}-\\d{2}-\\d{2}$')
    && d.cat in ['meal','cafe','move','stay','play','shop','etc']
    && d.what is string && d.what.size() >= 1 && d.what.size() <= 40
    && (d.paidBy in members(cid)
        || (d.paidBy == 'both' && d.shares.keys().hasOnly(members(cid)) && d.shares.size() == 2
            && d.shares[members(cid)[0]] + d.shares[members(cid)[1]] == d.amount
            && d.shares[members(cid)[0]] >= 1 && d.shares[members(cid)[1]] >= 1));
}
```
(`isMember` · `members`는 저장소에 있는 것을 쓰고, 없으면 couple 문서의 members로 같은 뜻을 만들어 주세요)

## 5. 숫자 표기 (`summary.js`)
- 합계 · 줄 금액: `446,200원`
- 사람별 · 칩: 1만 원 이상 `22.1만 원`(만 단위 소수 한 자리, `.0`은 뺌), 아래 `8,000원`
- %: 반올림하고 둘의 합은 늘 100. 합계 0이면 %를 보이지 않음
- 요약 한 줄: 같으면 「이번 달은 똑같이 냈어요」, 다르면 「이번 달은 {이름}{이/가} {차액}원 더 냈어요」 (받침 따라 이/가)
- 분류 칩: 금액 큰 순, 같으면 칩 기본 순서
