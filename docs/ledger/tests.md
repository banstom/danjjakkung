## B. 규칙 (에뮬레이터)
- R1 커플이 아닌 사람은 읽기 · 쓰기 거부
- R2 amount 0 · 1억 · 소수 · 문자열 거부
- R3 both인데 shares 합 ≠ amount, 한쪽 0, 세 사람 키 → 거부
- R4 paidBy가 커플이 아닌 uid → 거부
- R5 updatedBy가 나 아님 → 거부
- R6 단짝이 적은 기록을 내가 고치기 · 지우기 → 허용

## C. 화면 (Playwright)
- U1 「숙소 12만 반반」 입력 → 둘이 나눔 · 60,000 / 60,000 · 숙소 칩 (L3)
- U2 몫 칸 준민을 70,000으로 → 단짝 칸 50,000, 막대 58 / 42
- U3 「선물 포장지 8000」 → 누가 강조 + 기타 점선 + 안내 두 줄, 저장 가능 (L5)
- U4 「저녁 내가」 → 오류 문구, 저장 비활성 (L6)
- U5 누가를 「단짝」으로 직접 누른 뒤 한 줄 끝에 「반반」을 더 써도 단짝 그대로
- U6 저장 → 목록 맨 위, 요약 카드 · 칩 · 전체 탭 카드 숫자가 함께 바뀜
- U7 줄 누름 → 고치기 → 금액 바꿔 저장 → 숫자 반영. 지우기 → 확인 → 사라짐 (두 브라우저에서 단짝 화면도)
- U8 칩 누름 → 그 분류만 + 「교통만 · 73,500원 · 2건」, 다시 누르면 해제
- U9 12월(빈 달) → L10, 막대 · % 숨김
- U10 화면을 보는 사람이 바뀌면 왼쪽 · 오른쪽도 바뀜(단짝으로 로그인하면 단짝이 왼쪽, 문구 「이번 달은 단짝이 …」는 그대로)
- U11 320px · 375px 넘침 없음, 14개 테마(+겨울 두 개 낮밤) 스크린샷, 목업 PNG와 대조
