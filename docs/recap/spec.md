- 사람 순서: **화면을 보는 사람이 먼저**(`cardText(card, recap, viewerUid)`). 저장 문서에는 순서 없이 uid로
- 「모두」 규칙: 그날 해야 할 루틴이 있는 사람이 모두 자기 것을 다 했으면 full, 한 사람만이면 half, 아무도 못 했으면 none, 둘 다 해야 할 루틴이 없으면 빈 칸(빗금). **루틴 탭 달력의 「모두」 규칙과 같아야 해요** — 저장소 규칙이 다르면 그쪽을 따르고 `## 바뀐 것`에 적기
- 연속 날짜: 빈 칸(해야 할 루틴 없음)은 이어짐을 끊지 않음
- 함께 보낸 시간: 함께 일정만, 겹치면 합쳐 한 번, 기간 밖은 잘라 냄, 반올림
- 「가장 많은 날」이 같으면 이른 날
- 지도 별점 가장 높은 방문: 그 방문 두 사람 별점 평균 → 별점 개수 → 늦은 날

## 4. 서버 함수 · 데이터
```
monthlyRecap   (Cloud Functions 2세대, asia-northeast3, 매달 1일 03:00 Asia/Seoul)
  커플마다: 지난달 데이터 읽기 → computeRecap(data, prevData) → couples/{cid}/recaps/{YYYY-MM} 저장
  1월 1일에는 recaps/{YYYY}(1년치)도 계산
recapNotify    (매달 1일 09:00) — recaps 문서가 있고 users.recap != false 인 사람에게 FCM
  알림: 「11월의 단짝꿍이 나왔어요」 · 「한 장씩 넘겨 보세요」 → /review?recap=2026-11
  1월 1일: 「2026년의 단짝꿍이 나왔어요」 (12월 월말결산 알림은 보내지 않음)
```
- `recaps/{key}` = `computeRecap` 결과 그대로 + `createdAt`. **카드 화면은 이 문서만 읽어요**(빠르고, 나중에 다시 봐도 같은 숫자)
- 결산 뒤에 기록을 고쳐도 숫자는 그대로. 「다시 계산」은 나중 후보
- `prevData`: 앞 기간 데이터를 같이 읽어 계산(앞 기간 recaps 문서는 비교용으로 쓰지 않음 — 루틴별 비교가 필요해서)
- 입력 모양(`compose.js` 맨 위 주석)으로 바꾸는 일은 서버 함수의 '읽기' 모듈 한 곳에서만. 저장소 컬렉션 이름 · 필드가 다르면 거기서 맞춰요
- 읽는 양: 커플 하나에 한 달치 컬렉션 9개 × 두 달(이번 + 지난). Spark 한도 안
- 단짝이 된 날보다 이른 달은 만들지 않음. 단짝이 된 달은 만들되 비교 없음
- `firestore.rules`: `couples/{cid}/recaps/{key}` 읽기는 members만, 쓰기는 아무도(서버 함수만)
- 알림 스위치: 알림 시트에 「매달 1일 결산 알림」(`users/{uid}.recap`, 기본 켬)

### 입력 모양 (`computeRecap(data, prevData)`)
```
period     {kind:'month', key:'2026-11'} | {kind:'year', key:'2026'}
people     [{uid, name}, {uid, name}]
coupleSince 'YYYY-MM-DD'
routines   [{id, owner, name, days:[0..6 월=0], createdAt, deletedAt?}]
checks     [{routineId, date}]                 해낸 기록만
todos      [{id, doneAt|null, doneBy, shared}]
kungs      [{at:'YYYY-MM-DD', from}]
events     [{start:'YYYY-MM-DDTHH:mm', end, shared}]   서울 시각
places     [{code, name, visits:[{id,date}], entries:{uid:{visitId:{stars,note}}}}]   R2 이후 구조
meals      [{date, shared}]
goalDays   {uid: ['YYYY-MM-DD']}               식단 기능이 판단한 '목표 맞춘 날'만 (몸 정보 없이)
spends     단짝 영수증 기록 (영수증이 아직 없으면 [])
```
