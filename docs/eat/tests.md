## D. 가이드라인 검사 (저장소 기존 검사에 더하기)
- 이름 「출출 쿠키」가 `text.js` 말고 다른 파일에 없음
- 색 값(hex · rgb)은 `tokens.css`에만 — 쿠키 그림 토큰 `--ck-*`도 거기에 (그림 SVG에 색 값 없음)
- `--warn`은 빼기 확인 · 오류에만
- 글꼴은 프리텐다드, 아이콘은 기존 선 아이콘 / 토스페이스
