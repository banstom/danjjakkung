# 단짝꿍 — 현황 (2026-10-28)

## 끝난 것
- 아래 탭: 루틴 · 시간표 · 할 일
- 할 일: 위 「함께 할 일」(둘 다 체크) + 다진 | 준민 두 칸(본인만 체크), 3개까지 + 더 보기, 완료 접기,
  정렬 = 지난 일 → 오늘 → 이번 주 → 나중에 → 기한 없음
- 시간표: 주 | 일 전환, 매주 · 한 번 · 함께 일정, 일 보기 「지금」 상태, 내 일정만(함께는 둘 다) 수정
  · 쉬는 날 (10/28, v19): 매주 일정 칸을 누르면 「이날만 쉬기」 · 「이번 주 모두 쉬기」. 그날은 시간표에서 빠지고 요일 목록 · 일 보기에 「쉬어요」로 남음(눌러 되돌리기)
    저장 모양 skip: ['YYYY-MM-DD'] (매주 일정만, 60개까지, 4주 지난 날은 정리). 모르는 필드는 고쳐 저장해도 그대로 둠(extra)
  · 오늘 표시 (10/28, v19): 글자색 계열(--today) — 사람 색 후보 · 함께 색과 안 겹침, 주 보기 오늘 칸에 지금 선
  · 카테고리 직접 고치기 (10/28, v21): 일정 폼 카테고리 칩 끝 「✎ 편집」 → 「카테고리」 시트. 둘이 같은 목록(cats 컬렉션)
    새로 만들기 · 이름(8자) · 아이콘(토스페이스 40개 중) 바꾸기 · 지우기, 16개까지. 기본 6개도 바꾸고 지울 수 있음
    저장 모양 cats/<id>: { name, icon, order, updatedBy, updatedAt }, 기본 카테고리를 지우면 { deleted: true } 표시, 새로 만든 것은 문서 삭제
    문서가 없으면 기본 6개. 일정은 cat 에 id 만 — 지운 카테고리를 쓰던 일정은 아이콘 없이 보임
    토스페이스 글꼴 묶음 새로 만듦(scripts/tossface-subset.py) → 💼 💞 📌 도 토스페이스로
- 푸시 알림: 서버(서울 리전) 배포 완료 — 짝꿍 완료 알림, 저녁 미완료 알림(30분마다), 테스트 알림
  · Blaze + ₩40,000 선불, 예산 알림 있음, 서버 파일 정리 정책(1일), notifyLog TTL(expireAt)
- 테마: 계절 자동 색 → 사용자가 고르는 6종(Soft Pastel · Cosmic Dream · Ocean Breeze · Forest Diary · Vintage Film · Blue Hour)
  · 🎨 버튼 → 미니 화면 카드 시트(시안 A), 고르면 바로 적용, 이 기기에 저장, 처음엔 휴대폰 다크 모드면 Cosmic Dream
  · 나 · 상대 색 (10/28, v18): 테마 시트 위 「<테마> · 사람 색」에서 테마마다 8색 중 고름. 내 화면에만, 내 계정(users.colors)에 저장 → 내 모든 기기 같음.
