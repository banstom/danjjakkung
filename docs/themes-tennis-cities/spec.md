## 2. 색 토큰
- `tokens-tennis-cities.css` 여덟 판. 이름은 봄소풍 판과 같음(`--toast-fg`는 저장소 이름, 목업은 `--toast-text`)
- 스킨 토큰: `--head-w: 72px`, `--dash` 낮 = `--sh`와 같은 값, 밤 = 테니스 `#3A5650` · 포르투 `#3A4A70` · 프라하 `#40465A` · 토스카나 `#4E4052`
- 대비: `contrast.md` — 글자 20쌍 × 8판 모두 4.5:1 이상(가장 낮은 것 프라하 낮 `--sub`/`--raised` 5.28), 외곽선 · 달력 꽉 찬 칸 3:1 이상

## 3. 장식 (`pixel-skin-tennis-cities.css`)
- 머리 장식: 24×14칸 SVG × 3배(72×42) 가로 반복, 밤 24×20칸(72×60) → 밤 판은 머리말을 56px 내림
- 바탕: 28×28칸 SVG × 3배(84px) + 24px 옅은 체크
- 밤 판 고른 탭 테두리 = `--btn-lo`
- SVG 안 색은 파일에 고정 — 색 하드코딩 검사에서 그림 · 장식 파일은 예외

- S1 크기가 테마마다 다름 — 머리말 높이를 S1에 맞춰 늘리지 말고 오른쪽 아래에 붙여 두기
