## C. 화면 · 실기기 (구현 계정)
- 목업과 대조: E1 + F01~F16 (상태 넷 — 빈 자리 · 접힌 쪽지 · 펴진 쪽지 — 이 목업과 같은지)
- 두 기기(두 계정)로: 한쪽이 남기면 다른 쪽 입구가 「단짝이 남겼어요」로 바뀌고 단짝 쪽지는 접혀 있음 → 내가 남기면 펴짐
- 두 기기가 같은 순간 처음 열어도 질문이 하나 (`qdays/{오늘}` 문서 하나)
- 다른 질문을 한쪽이 바꾸면 다른 쪽도 바뀐 질문
- 자정 넘기기: 23:59에 열어 둔 화면이 00:00 뒤 다시 그릴 때 새 질문
- 알림: 21:00 안 답한 사람만 · 단짝이 답하면 · 스위치 끄면 안 옴 · 알림 누르면 질문 화면
- 320px · 375px 넘침 없음, 14개 테마 스크린샷, 어둡게
- 접힌 쪽지 글이 화면 어디에도(입구 · 알림 · 지난 쪽지) 새지 않는지
