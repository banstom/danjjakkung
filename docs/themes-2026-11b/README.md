## 2. 11-24에 정한 것 (사용자 확정)
- **색 기준**: 그림이 있는 도트 테마는 다른 테마와 색이 겹쳐도 됨 → 컨셉에 가장 맞는 색. 남는 규칙 둘: 빨강은 경고에만(넓은 버튼 색으로 안 씀), 글씨 대비 4.5:1
- 그래서 캠핑 · 프라하 버튼 색이 바뀜 (`themes-recolor`). 시드니도 하버 파랑으로 바뀌었는데 아직 안 넘긴 테마라 `themes-travel-5`에 바뀐 값으로 들어 있음
- **묶음**: 여행 · 도시를 따로 안 나눔 → 여행 하나 + 나들이
- 영화관은 빨강 · 검정이지만 **버튼은 검정(밤은 스크린 빛 크림)**. 빨강은 커튼 · 강조 칸 · 제목 점에만 — 경고 빨강과 안 헷갈리게

## 3. 단계 (이 순서로)

| **TS2** | `themes-sheet-2` | 시트 묶음 표 · 이번 달 표만 바꿈 (TS1을 아직 안 했으면 TS1을 11-24 판으로 하고 TS2는 건너뜀) | `themes-sheet/` |

- **다른 테마 화면은 바뀌면 안 됨** (RC1의 세 판, TS2의 시트만 바뀜)
- 화면을 새로 그려야 하면 구현하지 말고 기획 계정에 목업 요청

종합 묶음 1(docs/themes-2026-11/)이 main에 합쳐졌는지 먼저 확인하고, 3절대로 모음 브랜치를 정해서(안 합쳐졌으면 themes-2026-11 그대로, 합쳐졌으면 main에서 themes-2026-11b) 거기서 따서 RC1을 해 줘.
