# 시험 목록 — 테마 시트 (C안, 11-24 고침)

## 자동
| # | 시험 |
|---|---|
| S1 | 모든 테마에 `group`이 있고 값은 `season` · `travel` · `outing` · `basic` 중 하나 |
| S2 | 묶음 순서 = 계절 · 기념일 → 여행 → 나들이 → 기본, 묶음 안 순서 = spec 2절 표 (**11-24 표**: 여행 10 · 나들이 7) |
| S3 | 시트를 열면 지금 테마가 든 묶음만 펼쳐져 있음 |
| S4 | 다른 묶음 줄을 누르면 그 묶음만 펼쳐지고 앞의 것은 접힘, 펼친 줄을 다시 누르면 접힘 |
| S5 | 이번 달 카드 = spec 3절 표 (**11-24 표**, 1~12월 모두), 서울 날짜 기준 (UTC 자정 근처 시각으로 확인) |
| S6 | 표의 테마가 아직 없으면 그 칸만 빠지고, 둘 다 없으면 「○월에 어울리는 테마」가 안 보임 |
| S7 | 묶음 줄 개수 · 이름 나열이 실제 들어간 테마 수와 같고, 색 띠는 최대 5칸 |
| S8 | 「다른 테마 더 보기」가 없음 |
| S9 | 목록 줄은 `button`이고 `aria-expanded`가 펼침 상태와 같음 |

## 손으로
| # | 확인 |
|---|---|
| M1 | 목업 3장과 나란히 대조 (낮 · 밤) |
| M2 | 320px에서 여행 줄(10개) 이름 나열이 두 줄에서 말줄임, 색 띠가 넘치지 않음 |
| M3 | 소프트 파스텔 · 코스믹 드림(도트 아님)으로 바꿔도 시트가 깨지지 않음 |
